# ГЛУБОКИЙ АНАЛИЗ СИСТЕМЫ УПРАВЛЕНИЯ ИНВЕРТОРОМ MMA

## 1. ТЕКУЩИЙ РЕЖИМ СИСТЕМЫ

### 1.1 Определение режима

**Система находится в режиме STANDBY (0xA5)**

Признаки:
- Ток регулируется энкодером ✓
- Ошибки не мигают ✓
- На экране отображается уставка тока и статус HS/AF/AS

### 1.2 Состояние FSM

```
Inverter.state = SYS_STATE_STANDBY (0xA5)
```

**Условия нахождения в STANDBY:**
- Нет активных аварий (`Inverter.fault_code == 0`)
- UCC3895 не в аварии (`UCC3895_Is_Fault_Active() == false`)
- Напряжение дуги > порога анти-залипания (`raw_voltage >= ADC_THRES_ANTI_STICK = 410`)
- Системный таймер не превысил таймаутов перехода

## 3. МАТЕМАТИКА ФИЛЬТРАЦИИ (EMA)

### 3.1 Формула EMA-фильтра

```
y[n] = α · x[n] + (1 - α) · y[n-1]
```

Где:
- `y[n]` — текущее отфильтрованное значение
- `x[n]` — новое измерение (код АЦП 0..4095)
- `α` — коэффициент сглаживания (0 < α < 1)

### 3.2 Коэффициенты α по каналам

| Канал | α | Постоянная времени τ | Задержка ~95% |
|-------|---|----------------------|---------------|
| Ток дуги | 0.30 | 1.5 выборки = 0.075 мс | 0.15 мс |
| Напряжение | 0.20 | 2.5 выборок = 0.125 мс | 0.25 мс |
| +15В | 0.05 | 10 выборок = 0.5 мс | 1.0 мс |
| T IGBT | 0.01 | 50 выборок = 2.5 мс | 5.0 мс |
| T диодов | 0.01 | 50 выборок = 2.5 мс | 5.0 мс |
| Ток кулера | 0.05 | 10 выборок = 0.5 мс | 1.0 мс |

### 3.3 Префилл EMA

При старте все фильтры инициализируются значением **2048** (середина шкалы):

```c
filtered_code_values[i] = 2048.0f;  // ~50В на дуге, ~60°C для NTC
```

**Цель:** избежать ложных аварий до прихода первых данных DMA.

### 3.4 Оверсэмплинг

```
Буфер DMA: 160 слов (6 каналов × 16 выборок × 2 для Ping-Pong)
Размер окна: 16 выборок на канал
```

**Математика усреднения:**
```
avg = Σ(x[i]) / 16,  i = 0..15
```

**Эквивалентное подавление шума:** √16 = 4× (12 дБ)

## 4. МАТЕМАТИКА ПИ-РЕГУЛЯТОРА ТОКА

### 4.1 Параметры

| Параметр | Значение | Единицы |
|----------|----------|---------|
| Kp | 0.5 | В/А |
| Ki | 15.0 | с⁻¹ |
| dt | 0.000050 | с (50 мкс) |
| Ki·dt | 0.00075 | В/(А·такт) |
| out_min | 0.0 | В |
| out_max | 3.3 | В |

### 4.2 Дискретная формула ПИ

```
error[n] = setpoint - feedback[n]

p_term = Kp · error[n]                    // Пропорциональная часть
i_term = i_term[n-1] + Ki·dt · error[n]   // Интегральная часть

output[n] = p_term + i_term               // 0..3.3 В
```

### 4.3 P-гейт (защита холостого хода)

```c
if (current_feedback > 3.0f) {
    p_term = Kp * error;  // P работает только при токе > 3А
} else {
    p_term = 0;           // На ХХ P = 0, старт только через интегратор
}
```

**Эффект:** Мягкий старт — интегратор набирает ~1В за 15 мс при ошибке 90А.

### 4.4 Anti-Windup (Clamping)

```
if (output ∈ [out_min, out_max]) {
    integrator += Ki·dt·error;  // Обычная интеграция
} else if (output > out_max && error < 0) {
    integrator += Ki·dt·error;  // Интеграция на выход из насыщения
} else if (output < out_min && error > 0) {
    integrator += Ki·dt·error;  // Интеграция на выход из насыщения
}
// Иначе: интегратор заблокирован (windup предотвращен)
```

### 4.5 Передаточная функция

```
G(s) = Kp + Ki/s = (Kp·s + Ki)/s

В дискретной области (z-преобразование):
G(z) = Kp + Ki·dt·z/(z-1)
```

## 5. МАТЕМАТИКА OCV-РЕГУЛЯТОРА (STANDBY)

### 5.1 Параметры

| Параметр | Значение | Единицы |
|----------|----------|---------|
| Kp_ocv | 0.08 | В/В |
| V_target (OCV) | 70.0 | В |
| V_target (VRD) | 24.0 | В |
| out_max | 1.0 | В |

### 5.2 Формула

```
ctrl = Kp_ocv × (V_target - V_measured)

if (ctrl < 0) ctrl = 0;
if (ctrl > 1.0) ctrl = 1.0;
```

### 5.3 Логика выбора цели

```c
float v_target = (Is_VRD_Enabled()) ? MMA_VRD_TARGET_V : MMA_OCV_TARGET_V;
```

| Режим | VRD | Цель ХХ |
|-------|-----|---------|
| TOGGLES_ONLY | Выкл | 70В |
| VRD_ONLY | Вкл | 24В |
| BOTH | По тумблеру | 24В или 70В |

| Текущее состояние | Условие | Задержка | Следующее состояние |
|-------------------|---------|----------|---------------------|
| STANDBY | U < 410 (~10В) | 2 мс | HOT_START или WELDING |
| STANDBY | U > 2459 (~60В) | 100 мс | STANDBY (обрыв дуги) |
| HOT_START | Таймер | 700 мс | WELDING |
| HOT_START | U < 410 (~10В) | 200 мс | ANTI_STICK или WELDING |
| WELDING | U < 778 (~19В) | 10 мс | ARC_FORCE |
| WELDING | U < 410 (~10В) | 200 мс | ANTI_STICK или WELDING |
| ARC_FORCE | Таймер | 5 мс | WELDING |
| ANTI_STICK | Таймер | 400 мс | STANDBY |
| ANTI_STICK | U > 778 (~19В) | мгновенно | STANDBY |

### 6.3 Паттерны защиты от бит-флипа

```c
typedef enum {
    SYS_STATE_STANDBY    = 0xA5U,  // 10100101
    SYS_STATE_HOT_START  = 0x5AU,  // 01011010
    SYS_STATE_WELDING    = 0x3CU,  // 00111100
    SYS_STATE_ARC_FORCE  = 0xC3U,  // 11000011
    SYS_STATE_ANTI_STICK = 0x96U,  // 10010110
    SYS_STATE_FAULT      = 0x69U   // 01101001
} mma_state_t;
```

**Свойство:** Каждый паттерн имеет ≥4 битовых переворотов от любого другого.
Неизвестное значение → переход в FAULT.

## 9. СИСТЕМА АВАРИЙ

### 9.1 Коды ошибок

| Код | Название | Условие | Экран |
|-----|----------|---------|-------|
| 0x01 | OVERHEAT_IGBT | T < 1200 (~85°C) | "OVERHEAT" |
| 0x02 | LOW_15V | +15В < 2457 (~12В) | "220V~!" |
| 0x03 | FAN_BLOCKED | I_кулера > 3500 или < 40 | "NO FAN" |
| 0x04 | OVERCURRENT | Аппаратная отсечка EXTI12 | "SHORT" |
| 0x05 | SENSOR_OPEN | T < 50 или T > 4000 | "TSENSOR" |
| 0x06 | OVERHEAT_DIO | T_диодов < порог | "OVERHEAT" |
| 0x07 | POWER_FAIL | PVD (VDD < 2.8В) | "LOW VDD" |
| 0x08 | CSS_FAIL | Отказ HSE | "CLK ERR" |

### 9.2 Логика аварий

```
Любая авария → FSM_MMA_Force_Fault()
                    ↓
              Inverter.state = FAULT
                    ↓
              UCC3895_Disable()
                    ↓
              ШИМ = 0, выход закрыт
                    ↓
              Экран: "!!! ALARM !!!" + причина
                    ↓
              Лок до RESET (POWER CYCLE)
```

## 10. ЭНКОДЕР И МЕНЮ

### 10.1 Режимы работы энкодера

| Состояние | Вращение | Клик | Удержание ≥1с |
|-----------|----------|------|---------------|
| STANDBY (вне меню) | Изменение тока | Запись во flash | Вход в меню |
| STANDBY (в меню) | Изменение параметра | Следующий экран | Выход из меню |
| FAULT | Игнорируется | Сброс аварии | Игнорируется |

### 10.2 Параметры меню

| AS время (мс) | 200 | 1000 | 50 | 400 |

## 12. ВЫВОДЫ

### 12.1 Текущее состояние системы

1. **Режим:** STANDBY (0xA5)
2. **OCV-регулятор:** Активен, целевое напряжение 70В (или 24В при VRD)
3. **PI-регулятор:** Сброшен (не активен в STANDBY)
4. **Измерительная цепь:** Действительна (данные DMA получены)
5. **Аварии:** Отсутствуют

### 12.2 Безопасность

- Все контуры защиты активны
- Аварии лочатся до POWER CYCLE
- Бит-флип состояния → автоматический FAULT
- Watchdog предотвращает зависание

### 12.3 Рекомендации

1. Для проверки кнопки: удерживайте ≥1 сек в STANDBY
2. Для входа в меню: система должна быть в STANDBY (не FAULT)
3. Для проверки аварий: отключите делители на АЦП
