Статус: этап «минимального оживления» (пп. 1–4 + 8 плана восстановления).
Плата в разработке — карта зафиксирована как проектное решение, источник истины: `f411_ucc3895.ioc`.

## 2. Тактирование (RM0383)

HSE 25 МГц → /PLLM(25)=1 МГц → ×PLLN(192)=192 МГц → /PLLP(2) = **SYSCLK 96 МГц**
FLASH 3WS, VOS Scale 1, APB1=48 МГц (таймеры 96 МГц), APB2=96 МГц (таймеры 96 МГц), TIMPRE=×2.

| Таймер | PSC/ARR | Частота | Назначение |
|---|---|---|---|
| TIM2 | 0 / 4799 | **20 кГц (50 мкс)** | Тик FSM + ПИ-регулятора (UPDATE IRQ, prio 1) |

## 4. АЦП + DMA (RM0383 гл. 13, 11)

- ADC1: PCLK2/4 = 24 МГц, **6 рангов** (IN0..IN3 = PA0..PA3, IN5 = PA5, IN8 = PB0),
  144 такта выборки, continuous, выравнивание вправо; у STM32F4 ADC калибровка
  заводская (битов ADCAL/ADRDY нет — это фичи F3/F7);
- DMA2_Stream0: circular, halfword, NDTR = 192 (2 окна по 96), HT/TC IRQ (prio 3);
- окно = 6 каналов × 16 выборок × 6.5 мкс = **624 мкс** (HT каждые 624 мкс, TC 1.248 мс);
  EMA-фильтры на 6 каналов (α: ток 0.30, U 0.20, 15В 0.05, NTC 0.01, вентилятор 0.05);
- масштабы: 4095 кодов = 200 А / 100 В / 20 В / (NTC).

## 5. Осознанные отклонения и отложенные пункты

1. ✅ ВЫПОЛНЕНО (п.9): TIM11 ARR=1000 → ШИМ 23.98 кГц (вне слышимого диапазона, в полосе
   Intel-спеки 21–28 кГц для 4-pin вентиляторов); шкала cooling.c 0…1000 теперь
   честные duty 0…100 % (раньше максимум был 1.5 % — вентилятор фактически не крутился).
2. ✅ ВЫПОЛНЕНО: 6-канальный АЦП — TIM2_CH1 перенесён на PA15 (PA5 → ADC1_IN5, NTC диодов),
   FAN_CURR → PB0 (ADC12_IN8). Защиты NTC-диодов и обрыва/КЗ кулера в cooling.c активны.
   Примечание: PA15 по сбросу — JTDI (JTAG); настройка AF1 освобождает пин, SWD сохранён.
3. ✅ ВЫПОЛНЕНО (п.5): STANDBY = режим ОCV — мост включен, ПИ держит дежурный ток
   10 А (MMA_STANDBY_CURR); касание = V<30В при I>5А (фильтр 2 мс) -> HOT_START.
   UCC3895_Enable() убран из main(): мост включает FSM на первом тике TIM2.
4. ✅ ВЫПОЛНЕНО (п.12): PI_Regulator_Update() вызывается из FSM_MMA_Process на
   каждом тике 20 кГц; конверсия коды->амперы через CURRENT_AMPS_PER_CODE;
   выход -> UCC3895_Set_Control_Voltage -> TIM4 ЦАП; диагностика в
   Inverter.out_dac_value (шкала 0..1000).
5. ✅ ВЫПОЛНЕНО: детект обрыва дуги переведён на пару условий V>40В && I<5А
   (ADC_THRES_ARC_BREAK) — не зависит от точного значения ОCV конкретного железа.
6. Исключены из сборки: `welder.c`, `display.c`, `config_flash.c` (HAL/старая архитектура).
